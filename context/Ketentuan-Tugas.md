# Explorasi Hardskill Building Website UI

1. **Subject:** Project
2. **Types:** Hard Skill
3. **Topics Covered:** HTML, CSS dan Tailwind

---

## Goals

Dengan menyelesaikan assignment ini, student diharapkan dapat:
1. Mengimplementasikan penggunaan HTML, CSS, & Tailwind ke dalam website yang responsive.

---

## Objective

Tujuan dari assignment ini yaitu untuk mengukur pemahaman peserta dan pengaplikasian penggunaan HTML, CSS dan Bootstrap dalam materi pada Constructing Web Pages with HTML, Mastering HTML Elements, Mastering CSS, Unlocking Web Page Layout: Mastering Span, Div, and CSS Layout Techniques, Tailwind CSS Essentials, Tailwind CSS: Mastering Layout, Typography, and Visual Effects, dan Tailwind CSS: Building Dynamic and User-Engaging Web Interfaces. Selain itu hasil dari pembuatan project ini dapat digunakan untuk menambah portfolio peserta.

---

## Scenario

Sebagai seorang Web Developer, kamu diminta membuat halaman Web yang responsive & dapat memberikan referensi movie atau film untuk orang yang mau menonton film.

---

## Steps

Materi assignment ini dapat diakses di bab Constructing Web Pages with HTML, Mastering HTML Elements, Mastering CSS, Unlocking Web Page Layout: Mastering Span, Div, and CSS Layout Techniques, Tailwind CSS Essentials, Tailwind CSS: Mastering Layout, Typography, and Visual Effects, dan Tailwind CSS: Building Dynamic and User-Engaging Web Interfaces pada Modul FWD hal. 174 - 370.
